About

TrainBlock is a hypertrophy planning and workout tracking app, built collaboratively with Claude (Anthropic). All data is stored locally on your device.

Help
Getting started

This app helps you plan resistance-training programs and analyze their weekly volume per muscle group. A block is a multi-day training program. The Summary tab shows weighted sets per muscle group across the week, with colour coding to flag muscle groups that may be under- or over-trained.

Each row on a day tab is one exercise. Pick the exercise from the dropdown, then use −/+ or tap the number to set how many sets you plan to do.

Blocks (A, B, C…)

Tap a block button to switch to it. The top-right icons let you:

  • ＋ Add a new block (up to 26 total, A–Z)
  • 🗑 Delete the current block (asks first)
  • ↻ Reset the current block to empty

The text field below the block buttons lets you rename the current block (e.g. "Hypertrophy Phase 1"). Changes save automatically.

Days

The Days strip below the tabs lets you add or remove days from the current block (between 1 and 7). The day tab shows your label and total physical sets in parentheses, e.g. "Day 1 — Push (24)".

Each day has a label field at the top. Set it to whatever helps you remember (e.g. "Push", "Legs/Push", "Heavy day").

Set type chips (S, A, D, C, R, M)

Each exercise row has a small chip between the exercise dropdown and the set-count buttons. Tap it to choose how that exercise's sets should be counted toward your weekly volume. The chip turns into your accent colour when an intensifier is selected.

ChipType×What "1 set" means
SStraight1.0One standard set to ~0–3 RIR
AAMRAP1.0One set taken to failure
DDrop set1.5One top set + 2–3 weight drops
CCluster1.55×3 or similar with very short rest
RRest-pause2.0One set + 2–3 short-rest mini-sets
MMyo-rep2.5Activation set + 3–5 mini-sets at short rest

Multipliers approximate the hypertrophy stimulus of an intensified set vs a single straight set. They're estimates from coaching literature — wide error bars apply. Importantly, "1 set" of myo-rep means one full activation+mini-sets sequence, not each mini-set. The number on the row is how many such sequences you're doing.

Supersets & giant sets

Long-press any exercise row (except the first one in a day) to link it to the row above as a superset. Long-press again to unlink it. You can chain three or more rows together to create tri-sets or giant sets.

Visual cues:

  • A coloured accent bar runs down the left edge of any rows that are linked together
  • The first row of each group shows a small SUPERSET ×N badge with the group size
  • The +/− buttons, the chip, and the exercise dropdown all still work normally — long-press is detected on empty parts of the row only

Supersets are a purely organizational concept here. They don't change volume calculations — each exercise still counts its sets independently toward its muscle groups. The grouping just helps you remember which exercises you're pairing during execution.

Note: the Flexify export doesn't preserve superset grouping (Flexify's plan format doesn't support it). The exercises just stay in the order you have them.

Tracking workouts

When you've planned a day, a Start workout button appears at the top of the day tab. Tap it to open the workout tracker — a full-screen view where each planned exercise shows a strip of set chips you can tap to log.

  • Tap a chip to log a set. Enter weight and reps; tap Save.
  • Logged chips turn green with your actual numbers. If you fell short of a target rep count, the chip turns yellow instead.
  • + button at the end of each exercise adds an unplanned set.
  • Tap a logged chip to edit or delete it.
  • RIR (Reps in Reserve) is optional — tap "+ Add RIR" in the log modal if you want to track it.
  • Tap the exercise name to swap it for a different exercise mid-workout (handy when a machine is taken). Existing logged sets keep their original name; new ones use the swapped exercise.
  • Rest timer at the bottom auto-starts when you log a set. Tap to start/stop manually. Long-press the timer to pick a different default duration (30s through 5min).
  • Finish closes out the workout and saves it to history.
  • Close (×) leaves it as "in progress" — you can resume from the day tab later.

Only one in-progress workout at a time. Starting a new one from a different day will prompt before discarding any other in-progress session.

The log modal pre-fills weight and reps with (in order): an existing logged value if you're editing, the planned target if set, your last set in this session, or your last set of this exercise from any past session. A small "last time" hint shows what you did before so you can match or progress.

Planning targets

Optionally set a target weight × reps per exercise row in the planner. Long-press the sets number to open the target editor. Enter the weight and reps you're aiming for; save.

When a target is set, a small @ 185lb × 8-style hint appears below the row, and the workout tracker will pre-fill those numbers when you start logging. Logged sets that miss the rep target are flagged in yellow.

Targets are entirely optional — the tracker works fine without them.

History & progression graphs

Tap the 📈 icon in the top bar to open History. Three views:

  • Session list — every workout you've logged, most recent first. Tap a session to see its details. In-progress workouts get a highlighted border so you can resume them.
  • Session detail — shows each exercise with its sets and reps as little chips. Tap an exercise name to jump to its progression graph. A red Delete session button removes it permanently.
  • Progression graph — for any exercise, a scatter+line chart of your sets over time. Toggle between Weight (heaviest single set), Est 1RM (Epley formula), and Volume (weight × reps summed). Below the graph, a table breaks it down by day.

Browse by exercise from the top of the History list is the fastest way to find a graph if you remember the exercise but not the date.

Migrating Flexify history: if you've imported a Flexify CSV but haven't yet tracked native workouts, a "Migrate" button appears at the top of the History list. It groups your imported sets into one synthetic session per calendar day, flagged "IMPORTED" so you can tell them apart. Migration is non-destructive — your original Flexify data stays available.

The Summary's Actual mode automatically uses native sessions if any exist, falling back to raw Flexify history only if no sessions are present.

Exercise library

Tap an exercise dropdown to pick from grouped categories (Chest, Back/Lats, etc.). The list scrolls and has a search field at the top.

Each row has a small pencil (✎) icon that opens an editor where you can:

  • Built-in exercises: adjust the primary/secondary muscle weights to your liking. The name is locked. If you've edited a built-in, a Reset to default button restores the original.
  • Custom exercises: fully editable name and muscles. Delete removes the exercise and clears it from any row using it.

Tap ＋ Add custom exercise at the bottom of any dropdown to create a new one. Custom exercises appear in their own "Custom" group at the bottom.

Muscle weights: primary = 1.0 (the exercise's main target), secondary = 0.5 (a meaningful contributor). The summary multiplies your sets by these weights.

Summary tab

Shows weekly volume per muscle group. Tap any muscle card to expand a per-day exercise breakdown.

Colour coding (Planned mode):

  • <6 sets/week — likely below minimum effective dose
  • 6–9 sets/week — minimum effective range (per Pak et al.)
  • 10–14 sets/week — solid maintenance/growth
  • ≥15 sets/week — high-volume range

The Planned / Actual toggle at the top switches between your planned volume and your actual logged volume from imported Flexify history. Actual mode uses the last 4 weeks of history and scales the thresholds by 4× (so ≤24, 25–36, 40–59, ≥60).

History & progression graphs

The 📈 History button in the top bar opens a chronological list of every logged session. Tap a session to see its sets, or use Browse by exercise to pick an exercise and see its progression graph.

Graphs offer three metrics:

  • Weight — the load lifted per set
  • Est 1RM — Epley-formula estimated one-rep max from your actual sets (useful for trending strength when you're not maxing out)
  • Volume — weight × reps per set

The trend line connects your best set per day. Scatter dots show every individual logged set. Below the graph, a table summarizes each session with the best set, total volume, and set count.

Imported Flexify history (after migration) shows up in graphs alongside native sessions. Looks the same to the analytics.

Settings & backup

The ⚙ Settings button in the top bar opens a panel with:

  • Backup & restore — export a single JSON file containing everything (blocks, sessions, custom exercises, edited muscle weights, set-type multipliers, Flexify history, preferences). Import to restore on the same or a different device.
  • Summary data source — choose whether the Summary's Actual mode reads from native sessions or raw Flexify history.
  • Rest timer default — pick a default duration for the workout rest timer (30s–5m).
  • Preferred weight unit — lb or kg, used for new logged sets.
  • Flexify integration — export current block as a Flexify plan CSV, or import Flexify history.

If it's been more than 14 days since your last backup and you have logged data, a yellow banner appears asking you to back up. Tap Back up to do it immediately, or Later to snooze for another 14 days.

Flexify integration (legacy)

Now lives in the Settings panel. Two operations:

  • Export current block — saves the current block as a Flexify-compatible CSV file. Each day becomes a Flexify plan titled Block Name - Day Label. Exercises without a Flexify equivalent are skipped (a count appears in the status line).
  • Import history CSV — opens a file picker. Choose your graphs.csv from Flexify. The app reads every logged set, maps Flexify exercise names to ours, and stores them locally. Re-importing replaces the previous import.

From the History view, you can migrate Flexify history into native sessions as a one-time operation. After that, Flexify becomes optional — all your data lives in native sessions.

Storage & privacy

All your data lives in your phone's browser storage (localStorage). Nothing is uploaded anywhere. If you clear your browser data, blocks, sessions, custom exercises, and history are erased.

Use the Backup & restore feature in Settings to keep a JSON export safe. That's your insurance policy against data loss.

Tips
  • Hold the −/+ buttons to repeat-increment quickly.
  • Tap the number between −/+ to enter a value directly with a numpad.
  • If the keyboard pops up unwantedly when you tap a dropdown, tap on the list area instead of the search field — it's read-only by default and only activates the keyboard if you explicitly tap it.
  • The save indicator briefly shows "Saving…" then "Saved" — every change is auto-persisted.
