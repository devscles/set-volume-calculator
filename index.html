About

Shred Sheet is a hypertrophy planning and workout tracking app, built collaboratively with Claude (Anthropic). Born as a spreadsheet, now decidedly not one. All data is stored locally on your device.

Help
Getting started

This app helps you plan resistance-training programs and analyze their weekly volume per muscle group. A block is a multi-day training program. The Summary tab shows weighted sets per muscle group across the week, with colour coding to flag muscle groups that may be under- or over-trained.

Each row on a day tab is one exercise. Pick the exercise from the dropdown, then use −/+ or tap the number to set how many sets you plan to do.

Blocks (A, B, C…)

Tap a block button to switch to it. The top-right icons let you:

  • ＋ Add a new block (up to 26 total, A–Z)
  • 🗑 Delete the current block (asks first)
  • ↻ Reset the current block to empty

The text field below the block buttons lets you rename the current block (e.g. "Hypertrophy Phase 1"). Changes save automatically.

Days

The Days strip below the tabs lets you add or remove days from the current block (between 1 and 7). The day tab shows your label and total physical sets in parentheses, e.g. "Day 1 — Push (24)".

Each day has a label field at the top. Set it to whatever helps you remember (e.g. "Push", "Legs/Push", "Heavy day").

Set type chips (S, A, D, C, R, M)

Each exercise row has a small chip between the exercise dropdown and the set-count buttons. Tap it to choose how that exercise's sets should be counted toward your weekly volume. The chip turns into your accent colour when an intensifier is selected.

ChipType×What "1 set" means
SStraight1.0One standard set to ~0–3 RIR
AAMRAP1.0One set taken to failure
DDrop set1.5–2.5Top set + N drops; multiplier scales with drop count (see below)
CCluster1.55×3 or similar with very short rest
RRest-pause2.0One set + 2–3 short-rest mini-sets

These multipliers are defensible estimates, not precise measurements. The research on intensifier techniques is thin and the numbers were chosen as reasonable midpoints in the available literature. All multipliers are user-editable in Settings → Set type multipliers. If you disagree with any of these (and reasonable people do), change them.

Intensifier weighting & the literature

This is the most opinionated part of the app, so we want to be transparent about how we landed where we did and where the uncertainty is.

The basic question: if a straight set to ~0–3 RIR contributes 1 "set" toward your weekly volume, how much should an intensified set contribute?

What the literature actually says:

  • Rest-pause (Marshall et al., 2012): equated-volume comparisons show similar hypertrophy outcomes per equated rep. Rest-pause sequences allow ~50–100% more total reps than a straight set in the same time. We use 2.0×.
  • Myo-reps (Børge Fagerli, various): coaching framings put a full myo-rep sequence at "2–3 traditional sets." We use 2.5× as the midpoint. Crucially, "1 myo-rep set" means one full activation+mini-sets sequence, not each mini-set individually — otherwise the count would be wildly inflated.
  • Drop sets: Coleman et al. (2022) meta-analysis and the Gonzalez et al. (2025) narrative review both report that when volume is matched, drop sets and traditional training produce equivalent hypertrophy and strength. Drop sets accomplish that matched volume in ~30–70% less time, which is their main practical advantage. Past that, the literature is thin — none of the included studies tested multi-drop sequences (3+) the way bodybuilders typically perform them. Our tiered estimates: 1 drop = 1.5×, 2 drops = 2.0×, 3 drops = 2.5×, 4 drops = 2.75×, 5+ drops = 3.0× (plateau). The plateau reflects diminishing returns — each successive drop performs less work than the one before it (lighter load, fewer reps to failure) — and our genuine uncertainty about whether 6, 7, or more drops contribute meaningful additional stimulus. If you'd like the cap to behave differently (e.g. you find extended-drop sequences genuinely worth 3.5× or 4×), edit the tier 5 value in Settings.
  • Cluster sets: equated-volume research shows similar hypertrophy to traditional sets per equated rep, with potentially better mechanical performance. We use 1.5× reflecting the modest additional reps cluster format allows.

What we're guessing about: the precise multiplier for each technique relative to a straight set. Individual response varies enormously based on training age, recovery, exercise selection, and how strictly the technique is performed. A poorly-executed myo-rep with long rests between mini-sets is essentially a straight set; a tightly-executed one with very short rest is much more.

Why this matters for the Summary tab: if you do 4 myo-rep sets of curls (= 10 effective sets per our math) you'll see Biceps at 10 in the Summary. Whether that "really" represents the same biceps stimulus as 10 straight sets is unprovable — but it's a useful planning approximation that prevents you from accidentally over- or under-training a muscle.

If you want to change anything: Settings → Set type multipliers. You can edit any base value and the drop tiers individually. Changes apply immediately to all Summary calculations and the per-exercise Sets graph. Click "Reset all to defaults" to restore.

Supersets & giant sets

Each exercise row has a small chain icon button between the exercise picker and the set-type chip. Tap it to link the row with the one above as a superset. Tap again to unlink. You can chain three or more rows together to create tri-sets or giant sets.

Visual cues:

  • The chain button fills with your accent colour when a row is linked
  • A coloured accent bar runs down the left edge of any rows that are linked together
  • The first row of each group shows a small SUPERSET ×N badge with the group size
  • The chain button on row 1 of any day is disabled (no row above to link to)

Supersets are a purely organizational concept here. They don't change volume calculations — each exercise still counts its sets independently toward its muscle groups. The grouping just helps you remember which exercises you're pairing during execution.

Note: the Flexify export doesn't preserve superset grouping (Flexify's plan format doesn't support it). The exercises just stay in the order you have them.

Tracking workouts

When you've planned a day, a Start workout button appears at the top of the day tab. Tap it to open the workout tracker — a full-screen view where each planned exercise shows a strip of set chips you can tap to log.

  • Tap a chip to log a set. Enter weight and reps; tap Save.
  • Logged chips turn green with your actual numbers. If you fell short of a target rep count, the chip turns yellow instead.
  • + button at the end of each exercise adds an unplanned set.
  • Tap a logged chip to edit or delete it.
  • RIR (Reps in Reserve) is optional — tap "+ Add RIR" in the log modal if you want to track it.
  • Tap the exercise name to swap it for a different exercise mid-workout (handy when a machine is taken). Existing logged sets keep their original name; new ones use the swapped exercise.
  • Rest timer at the bottom auto-starts when you log a set. Tap to start/stop manually. Long-press the timer to pick a different default duration (30s through 5min).
  • Finish closes out the workout and saves it to history.
  • Close (×) leaves it as "in progress" — you can resume from the day tab later.

Only one in-progress workout at a time. Starting a new one from a different day will prompt before discarding any other in-progress session.

The log modal pre-fills weight and reps with (in order): an existing logged value if you're editing, the planned target if set, your last set in this session, or your last set of this exercise from any past session. A small "last time" hint shows what you did before so you can match or progress.

Myo-rep tracking: when the row's set type is set to M (Myo-rep), the log modal switches to a more detailed layout: Weight, Activation reps, and a row of mini-set inputs (default 4, adjustable with the −/+ buttons, up to 8). Blank mini-sets are ignored when you save. The set chip displays the full sequence, e.g. 185×15+5,5,5,3.

Drop set tracking: when the row's set type is set to D (Drop set), the workout view shows an inline card with two rows of chips: weights (top) and reps (bottom). The first slot is the initial set; subsequent slots are drops. After entering the initial weight, downstream blank weights auto-fill with 20% less than the previous slot, rounded to the nearest 5lb (or 2.5kg). You can edit any auto-suggested value, and the cascade only fills blanks — never overwrites what you've typed. The default layout shows 1 initial + 4 drops; use the −/+ buttons to add or remove drops (max 7 drops, 8 slots total). Empty drop slots are skipped when saving. The summary displays the sequence as 100lb×10 → 80lb×8 → 64lb×6.

How drop sets feed the graphs:

  • Weight graph: uses the initial (heaviest) weight, treated like any straight set
  • Est 1RM graph: uses the initial set's weight and reps (the heaviest single effort)
  • Volume graph: weight × total reps across the entire sequence (initial + all drops)
  • Sets graph: contribution depends on drop count — 1 drop = 1.5, 2 drops = 2.0, 3 drops = 2.5, 4 drops = 2.75, 5+ drops = 3.0 (plateau). See "Intensifier weighting" for details and how to adjust these.

How myo-reps feed the graphs:

  • Weight graph: uses the working weight (same as straight sets)
  • Est 1RM graph: uses the activation reps only (most representative of true working strength)
  • Volume graph: weight × total reps including all mini-sets (the actual work performed)
  • Sets graph: each myo-rep sequence contributes 2.5 effective sets per the same multiplier used in the Summary tab. Days that include intensifier sets are marked with a hollow (outlined) dot on the graph and an asterisk in the history table — so you can tell at a glance which trends are inflated by the multipliers vs straight-set work. Tap any dot for a per-type breakdown.
Planning targets

When you pick an exercise and set a number of sets, a row of pills appears below the row — one per set (for straight/AMRAP) or one per sequence (for drop sets, myo-reps, cluster, rest-pause). Each pill represents one effort and starts in an empty state showing the set number.

Tap a pill to set a target weight × reps for that specific set. Filled pills show the target inline like 185×8. Each set in a row can have its own target, so you can plan e.g. a top set heavier than the back-off sets.

For drop sets, the pill row shows the initial set followed by downward-arrow drop pills; an inline drops [−][+] control adjusts how many drops are in each sequence. Myo-rep, rest-pause, and cluster set types have similar inline controls for mini-sets / clusters.

Targets are entirely optional. When set, they flow into the workout tracker — the inline log cards pre-fill weight and reps with the target value, and logged sets that miss the rep target are flagged in yellow.

History & progression graphs

Tap the 📈 icon in the top bar to open History. Three views:

  • Session list — every workout you've logged, most recent first. Tap a session to see its details. In-progress workouts get a highlighted border so you can resume them.
  • Session detail — shows each exercise with its sets and reps as little chips. Tap an exercise name to jump to its progression graph. A red Delete session button removes it permanently.
  • Progression graph — for any exercise, a scatter+line chart of your sets over time. The trend line connects your best set per day. Below the graph, a table breaks it down by day.

Graph metrics:

  • Weight — the load lifted per set
  • Est 1RM — Epley-formula estimated one-rep max from your actual sets (useful for trending strength when you're not maxing out). Sets logged at 1 rep are treated as true 1RMs and drawn as squares instead of circles; multi-rep sets are estimated and drawn as circles. When a day has both a true 1RM and a higher Epley estimate from a multi-rep set, the true 1RM wins as the best-of-day point — a measured single is more truthful than an estimate.
  • Volume — weight × reps per set
  • Sets — daily aggregated effective set count, with set-type multipliers applied

Browse by exercise from the top of the History list is the fastest way to find a graph if you remember the exercise but not the date.

Migrating Flexify history: if you've imported a Flexify CSV but haven't yet tracked native workouts, a "Migrate" button appears at the top of the History list. It groups your imported sets into one synthetic session per calendar day, flagged "IMPORTED" so you can tell them apart. Migration is non-destructive — your original Flexify data stays available.

The Summary's Actual mode automatically uses native sessions if any exist, falling back to raw Flexify history only if no sessions are present.

Exercise library

Tap an exercise dropdown to pick from grouped categories (Chest, Back/Lats, etc.). The list scrolls and has a search field at the top.

Each row has a small pencil (✎) icon that opens an editor where you can:

  • Built-in exercises: adjust the primary/secondary muscle weights to your liking, and rename the exercise if the default name doesn't match your gym vocabulary. Renames propagate everywhere — planner rows, in-progress sessions, and past logged history. A Reset to default button restores the original muscle weights, and a separate Reset name to default button restores the original name.
  • Custom exercises: fully editable name and muscles. Renames also propagate to all past sessions so your progression history stays connected. Delete removes the exercise and clears it from any row using it.

Tap ＋ Add custom exercise at the bottom of any dropdown to create a new one. Custom exercises appear in their own "Custom" group at the bottom.

Muscle weights: primary = 1.0 (the exercise's main target), secondary = 0.5 (a meaningful contributor). The summary multiplies your sets by these weights.

Summary tab

Shows weekly volume per muscle group. Tap any muscle card to expand a per-day exercise breakdown.

Colour coding (Planned mode):

  • <6 sets/week — likely below minimum effective dose
  • 6–9 sets/week — minimum effective range (per Pak et al.)
  • 10–14 sets/week — solid maintenance/growth
  • ≥15 sets/week — high-volume range

The Planned / Actual toggle at the top switches between your planned volume and your actual logged volume from imported Flexify history. Actual mode uses the last 4 weeks of history and scales the thresholds by 4× (so ≤24, 25–36, 40–59, ≥60).

Settings & backup

The ⚙ Settings button in the top bar opens a panel with:

  • Backup & restore — export a single JSON file containing everything (blocks, sessions, custom exercises, edited muscle weights, set-type multipliers, Flexify history, preferences). Import to restore on the same or a different device.
  • Summary data source — choose whether the Summary's Actual mode reads from native sessions or raw Flexify history.
  • Rest timer default — pick a default duration for the workout rest timer (30s–5m).
  • Preferred weight unit — lb or kg, used for new logged sets.
  • Flexify integration — export current block as a Flexify plan CSV, or import Flexify history.

If it's been more than 14 days since your last backup and you have logged data, a yellow banner appears asking you to back up. Tap Back up to do it immediately, or Later to snooze for another 14 days.

Flexify integration (legacy)

Now lives in the Settings panel. Two operations:

  • Export current block — saves the current block as a Flexify-compatible CSV file. Each day becomes a Flexify plan titled Block Name - Day Label. Exercises without a Flexify equivalent are skipped (a count appears in the status line).
  • Import history CSV — opens a file picker. Choose your graphs.csv from Flexify. The app reads every logged set, maps Flexify exercise names to ours, and stores them locally. Re-importing replaces the previous import.

From the History view, you can migrate Flexify history into native sessions as a one-time operation. After that, Flexify becomes optional — all your data lives in native sessions.

Storage & privacy

All your data lives in your phone's browser storage (localStorage). Nothing is uploaded anywhere. If you clear your browser data, blocks, sessions, custom exercises, and history are erased.

Use the Backup & restore feature in Settings to keep a JSON export safe. That's your insurance policy against data loss.

Tips
  • Hold the −/+ buttons to repeat-increment quickly.
  • Tap the number between −/+ to enter a value directly with a numpad.
  • If the keyboard pops up unwantedly when you tap a dropdown, tap on the list area instead of the search field — it's read-only by default and only activates the keyboard if you explicitly tap it.
  • The save indicator briefly shows "Saving…" then "Saved" — every change is auto-persisted.
